## 页面交互

顶部悬浮区统一管理全部行业的时间区间、指标开关、数值标签与财务模式；各一级行业独立管理二级行业复选和底部互斥折叠页签。总控制块的“展开全部二级 / 收拢全部二级”统一全选或取消全页面二级行业，后续懒加载模块继承当前状态；各模块仍可单独调整。二级行业默认不勾选，勾选后在一级大图下方呈现，桌面每行三个，按该行业最新季度市值降序排列。取消移除对应小图；“全选”支持批量选中/取消。

快捷范围1、3、5、10、20年及全部，默认10年。总市值/PE/营收/归母净利开关同时作用于对应一级大图和小图。利润固定在柱底，数字位于柱底下方；关闭利润时营收仍保持完整高度。普通滚轮在图上也能滚动页面，区间通过快捷选项、季度选择及滑块调整。

PE分位按所选区间内不高于目标PE的有效正PE样本占比计算，含相等值；全部行业均采用有效正日度样本；以彩色横条和数值显示，低分位为绿色、中间为黄色、高分位为红色；主图随悬停目标季度变化，鼠标离开大图后恢复最新季度，小图汇总取最新季度。无有效样本显示—。各主图、小图顶部汇总始终显示总市值、PE、营收、归母净利润及PE分位，不随指标开关隐藏；图例仅控制绘图。

PE尖峰采用A规则：有效正PE至少8季，PE同时大于Q3+3×IQR及中位数3倍。先用非候选点计算纵轴上限；只有超出上限的候选点才压缩、虚线示意并标↑真实值。范围内候选仍按真实高度画实线。PE原值、分位、表格不修改，非正PE不显示且不跨缺口连线。

图表接近视口时才加载并初始化，各模块复用mountIndustry。补充数据表首次展开时生成。全部二级行业关闭时不创建小图实例。

## 数据与文件

全部31个一级行业、134个二级行业已于2026-11-13统一为与项目2同源的申万公布行情，使用同一份截至2026-11-10的原始响应快照。各模块的 `meta.valuationMethod` 均为 `sw_daily`。

- 行业市值：`sw_daily.total_mv÷10000`，万元转亿元；PE直接取 `sw_daily.pe`。季度点取季末最后交易日同日值，缺失留空，不沿用旧值或拼接公司汇总。
- PE分位：所选起始季度首日至结束季度末日内的全部有效正日度PE，含相等值。相同指数、观察日、区间时与项目2同公式。2.2显示1位小数，项目2通常取整数。默认日期区间不同，默认数值仍可不同。
- 财务：最新在市SW2021成分全公司合并报表固定回溯，上市后纳入。累计报表差分得到单季，另可显示最近4季。实际财报利润不是申万PE分母，不用市值÷PE推导真实利润。
- 公司市值：`daily_basic.total_mv÷10000`，与项目2公司明细同字段；含H股时为全部普通股按A股价格估值，不等于申万行业市值分拆。公司分组按申万二级市值排序，组内按公司市值排序。
- 财务与行情快照截至2026-11-10，图表最新完整财报季度2026Q3。每个指数按实际可得历史展示；2005年补查了全部165个代码，其中55个有返回，共13,310条。2006年后直接复用项目2缓存。
- 9个二级分类无申万行情：农业综合、其他家电、旅游零售、体育、本地生活服务、其他银行、社交、油气开采、医疗美容。财报有数据仍显示财务柱；无当前公司则财务也留空。林业行情截至2021-12-10，不将末值沿用到之后季度。
- 公开原始行情与请求校验信息在每个模块的 `sw-source.json`。`data.json/js`、`sectors.json/js`、`quarterly.csv`、`catalog.json/js`、说明和审计均已同步；`valuationDaily` 保存计算分位的日度PE。
- `sw-alignment-audit.json` 记录每个一级/二级历史覆盖和财务校验摘要；`all-industries-audit.json` 的 `valuationAlignment` 为现行申万口径。既有公司整体法审计标记为历史资料，不作为当前行业估值。
- `company-quarterly.csv`、公司TTM字段和旧财报缓存保留用于财务复核，不作为申万PE的分子/分母，不可直接用旧构建器覆盖申万行情。

中芯国际和奥精医疗最新季度使用有依据的机械估算并标*；萃华退缺少估算依据，保留缺失并标†，相应最近4季窗口留空。北交所最早从2021-11-15纳入，智新电子此前精选层阶段已剔除。各模块独立说明具体估算、缺失及历史覆盖。

详细约定见 [SW_DATA_CONTRACT.md](SW_DATA_CONTRACT.md)。重建：`python3 tools/align_sw_data.py`，从已保存的公开源响应重建全部模块，不联网、不重建财报。支持 `--project2 PATH --early-source PATH` 导入共同快照。

## 验证与发布

已核对165个指数分类的14,355个季度记录、项目2原窗口原观察日的385,793个PE分位输出（含无效或缺失值），以及495份源响应缓存。全部原有14,181个行业季度财务记录、259,089条公司季度明细、公司归属及估算与切换前一致；一二级财务仍可加总。市值与PE不强制与公司汇总或跨分类变更的一二级合计对账。

校验命令：`python3 tools/validate_sw_data.py`，加 `--project2 PATH` 可验证项目2全部原始分位输出。网页检查覆盖全部大图、小图、日度分位、默认状态、财务模式、公司分组、空值、折叠说明与手机布局。提交后在工作区运行 `python3 sync-site.py`，同步公开站点、新全览图仓库、本地副本和交付文件。

## 总标题与悬浮导航

页首显示“2.2 全览图”。其下为单行吸顶行业导航，顺序与最新市值排序一致。点击跳转到对应行业，页面滚动、二级图展开或折叠时自动更新当前行业高亮；横向导航会确保当前项可见。支持手机横滑、键盘链接操作、行业锚点及前进后退，遵循减少动态效果设置。

## 全局悬浮控制与最近4季

指标、时间范围、数值标签及财务模式统一控制全部一级/二级图，包括随后懒加载的图。任一主图滑块也更新全局区间。最近4季按该季与此前3季相加，窗口可以超出显示区间；不足4季、无样本或有财务缺失时留空，含估算保留标记。原季度数据不改动，底部明细仍是单季度；市值/PE不求和。

默认显示最近4季营收与归母净利润，PE曲线默认隐藏，顶部PE与分位始终显示；可通过全局开关恢复PE或切回单季度。懒加载行业及新增二级小图继承当前设置。

公司明细按二级行业分组，组间按最新季度行业总市值降序，组内按公司总市值降序。新增总市值（亿元）列，组标题列出行业总市值；搜索支持公司、代码和二级行业，估算筛选后仍保持该顺序及完整行业市值。
