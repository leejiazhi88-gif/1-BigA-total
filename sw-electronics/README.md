## 数据约定

- 行业市值/PE直接使用 sw_daily.total_mv÷10000（亿元）和 sw_daily.pe；季度点取季末同日，缺失留空，不用公司汇总补齐。历史行情共享项目2截至2026-11-10的响应，后续日度补充独立保存。
- PE分位是区间内正日度PE不高于目标PE的比例，包含相等值。快捷区间截至“最新”时向前推整年，默认2016-11-13—2026-11-13；手动起始季度从季度首日计。与项目2比较须对齐指数、观察日、区间。
- 财务按最新在市SW2021公司固定回溯，上市后纳入；北交所最早2021-11-15。合并累计报表差分为单季，取已披露最新可得调整版本。不存在用市值÷PE倒推实际利润。固定样本有存续样本偏差。
- 公司市值为 daily_basic.total_mv÷10000，全部普通股按A股价格估值；含H股时不等于两地实际市值相加，也不是申万行业市值逐股分拆。
- 无官方行情的9个二级分类保留空值；林业官方行情止于2021-12-10。实际财务仍可展示。
- PE非正不绘制；尖峰A规则同时超过Q3+3×IQR和中位数3倍，且超出普通纵轴上限才压缩虚线，原值和日度分位不变。

完整约定见 [SW_DATA_CONTRACT.md](SW_DATA_CONTRACT.md)。各模块 data/sectors JSON及JS、公司CSV、季度CSV、源响应、审计与说明同步。quarterly.csv仅含87个真实季度；公司CSV保留历史季末市值，并在最新季度添加 latestMarketCap/latestQuoteDate/latestQuoteCarried；网页公司表使用这三个最新字段。旧公司TTM及整体法审计仅作历史资料，不作为申万PE分子分母。

## 刷新、效率与发布

在项目目录运行 `python3 tools/refresh_data.py`，统一完成联网取数→重算→验证→封存。凭据从环境或本机配置读取，不进入公开仓库。每次重新核查近7个季度全市场合并报表，以及上次核查日以来的公告更正；如发现更早期间变动，扩展查询。累计差分依赖的上一期一并补齐；新增财报季度或缺少历史的新公司会停止并要求推进历史构建，禁止静默发布旧季度。

申万日行情按交易日批量取全部指数（439条/日）而非165次逐指数调用；范围很长时自动择较少请求方案。4路有界并发，不超过接口单次条数；财报达到9000条上限自动按公告日期拆分。停牌只为缺少最新报价的公司补查。来源内容与日期均未变化时跳过重复生成，仍重新联网并完整校验。此次优化复跑仅80次请求，先前244次；口径和165个指数最新值逐一对比一致。

freshness-audit.json记录当次核查日期、请求数、耗时、待披露状态和生成文件SHA256。refresh-source.json.gz保存公开参数、返回字段、响应及实际抓取时间，不含凭据。`python3 tools/check_freshness.py` 校验当天新查询、已披露不得估算、38133条近期公司财报差分、全部聚合、公司报价和文件哈希。缺失、过期或来源不匹配均阻止推送；不能仅修改页面更新日期。

校验：`python3 tools/validate_sw_data.py`，可加 `--project2 PATH` 核对共同历史分位。发布前提交主目录内相关文件，在原工作区运行 `python3 sync-site.py`（项目内副本 tools/sync_site.py），同步旧公开站点、新独立仓库、本地独立副本和outputs/zip。禁止force push；远端和本地有用户改动时先合并。同步入口也执行新鲜度门禁。
