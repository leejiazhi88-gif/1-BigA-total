## 页面交互

顶部悬浮区统一管理全部行业的时间区间、指标开关、数值标签与财务模式；各一级行业独立管理二级行业复选和底部互斥折叠页签。总控制块的“展开全部二级 / 收拢全部二级”统一全选或取消全页面二级行业，后续懒加载模块继承当前状态；各模块仍可单独调整。二级行业默认不勾选，勾选后在一级大图下方呈现，桌面每行三个，按该行业最新季度市值降序排列。取消移除对应小图；“全选”支持批量选中/取消。

快捷范围1、3、5、10、20年及全部，默认5年。总市值/PE/营收/归母净利开关同时作用于对应一级大图和小图。利润固定在柱底，数字位于柱底下方；关闭利润时营收仍保持完整高度。普通滚轮在图上也能滚动页面，区间通过快捷选项、季度选择及滑块调整。

PE分位按所选区间内不高于目标PE的有效正PE季度占比计算，含相等值；主图随悬停目标季度变化，小图汇总取最新季度。无有效样本显示—。各主图、小图顶部汇总始终显示总市值、PE、营收、归母净利润及PE分位，不随指标开关隐藏；图例仅控制绘图。

PE尖峰采用A规则：有效正PE至少8季，PE同时大于Q3+3×IQR及中位数3倍。先用非候选点计算纵轴上限；只有超出上限的候选点才压缩、虚线示意并标↑真实值。范围内候选仍按真实高度画实线。PE原值、分位、表格不修改，非正PE不显示且不跨缺口连线。

图表接近视口时才加载并初始化，各模块复用mountIndustry。补充数据表首次展开时生成。全部二级行业关闭时不创建小图实例。

## 数据与文件

- catalog.json/js：31行业、最新汇总及排序。
- data.json、sectors.json、company-quarterly.csv等：已核验电子快照及历史PE审计；智新电子已剔除2021Q2/Q3两个精选层阶段公司季度。
- bank/：已核验银行快照及其审计。
- industries/801xxx/：其余29个一级行业的相同结构数据，含meta、质量标记、估算、二级行业及逐公司明细。
- all-industries-audit.json：31行业对账、覆盖、排序及独立历史TTM核查。

源接口：index_classify(SW2021)、index_member_all、stock_basic、daily_basic、income_vip。行业成分查询不传src（传SW2021返回空），将返回的一级和二级代码与SW2021分类逐一核对。在市固定成分全部5580家无跨行业重复。新行业财务抓取2003Q1起，使用1/4/5类合并报表版本；原始取数缓存和构建/验证脚本位于工作区work/all-data及work/下，不作为网页运行依赖。

市值按季末最后交易日total_mv（万元÷10000为亿元），停牌缺失沿用此前最后有效数据，记录原日期，不重算股本变动。该字段按A股价格计总股本，含其他股份类别的公司也保持同字段，不额外叠加港股市值。

财务为营业总收入（缺失用营业收入）和归母净利润的累计差分，金额亿元。采用截至快照日可得版本；历史调整可能影响可比性。同一公告/报告期/类型的重复记录可用非空同源值补齐空字段，零值仍是已披露数据，所有补齐记录保存在工作区duplicate-field-fills.json。北交所样本最早自2021-11-15起纳入，不混入此前新三板阶段，67家上市边界规范化记录在工作区listing-adjustments.json。

PE为有效样本市值合计/TTM归母净利润合计，含亏损；正个股PE反推TTM，缺PE或沿用市值时按季末已公告财报重建。各版本只在实际公告日不晚于估值日时可用；无法重建同时剔除分子分母并显示覆盖，非正合计利润不适用。历史缺财务不填零，柱标†。最新缺报按上年同季营收×最近累计同比倍数，再乘最近累计归母净利率估算并标*，估算不用作PE分母。

最新季度中芯国际、奥精医疗使用明确标注估算。纺织服饰的萃华退缺少2026年财务依据，营收和利润保留缺失，明细及折叠说明中标出。银行等最新报表齐全的行业不估算。历史缺口、沿用市值和PE覆盖逐行业在质量表列出。

固定最新在市成分回溯有存续样本偏差，不是历年官方成分指数；不能用于无前视回测。银行、非银及工业企业收入结构不同，按各自合并利润表取数。

## 全局悬浮控制与最近4季

指标、时间范围、数值标签及财务模式统一控制全部一级/二级图，包括随后懒加载的图。任一主图滑块也更新全局区间。最近4季按该季与此前3季相加，窗口可以超出显示区间；不足4季、无样本或有财务缺失时留空，含估算保留标记。原季度数据不改动，底部明细仍是单季度；市值/PE不求和。

默认显示最近4季营收与归母净利润，PE曲线默认隐藏，顶部PE与分位始终显示；可通过全局开关恢复PE或切回单季度。懒加载行业及新增二级小图继承当前设置。

公司明细按二级行业分组，组间按最新季度行业总市值降序，组内按公司总市值降序。新增总市值（亿元）列，组标题列出行业总市值；搜索支持公司、代码和二级行业，估算筛选后仍保持该顺序及完整行业市值。
