# 申万电子季度研究

公开地址：https://leejiazhi88-gif.github.io/1-BigA-total/sw-electronics/

本页是独立静态页面，数据截至 2026-11-10；历史范围 2005Q1—2026Q3，共 87 季度。无需后端、账户或浏览器凭据，所有运行依赖随页面一起部署。不会自动更新数据。

## 文件

- `index.html`、`style.css`、`app.js`：页面、样式、交互。
- `echarts.min.js`：Apache ECharts 5.6.0，Apache-2.0 许可，文件头保留许可声明。
- `data.json`、`data.js`：相同数据快照；JS 版本使本地直接打开 HTML 也可浏览。
- `quarterly.csv`：87 季度汇总，金额为人民币亿元，PE 为倍数。
- `company-quarterly.csv`：17,693 条公司季度明细，含财务状态、公告日、行情日期、PE 利润来源。
- `data-manifest.json`：来源、范围、缺失及核验记录。

## 口径

申万2021版一级电子（801080.SI）。原始成分530个代码，与当前在市股票表交叉后521家；固定样本回溯、上市后纳入。2026Q3已有520家上市，2026Q4上市的粤芯半导体不计入Q3。含存续样本偏差，不等同于历年官方成分指数。

总市值使用季末最后交易日 `daily_basic.total_mv`（万元÷10,000为亿元）。缺当日有效值时沿用此前最后有效市值，保留原始日期；不重算停牌期间股本变化。网页左轴换算为万亿元。

PE采用整体法TTM含亏损。正PE公司的TTM利润由市值/个股PE(TTM)反推；负或缺PE及沿用历史市值的公司，使用季末当时已经披露的财报按“最新累计+上年全年−上年同期累计”重建TTM归母净利润。缺少利润数据时同时剔除分子、分母，并展示市值覆盖率；分母非正时PE留空。早期更正报表可能减少可重建的时点样本，历史部分期PE不是全样本值。

财务采用合并营业总收入（缺失用营业收入）与归母净利润，累计差分为单季，取截至快照日可得版本。早期个别缺失累计报表使用次年调整合并报表补充，差分可能受调整口径影响。2005Q3和2005Q4各缺闻泰前身一家单季财务，柱形为已知合计并标†；缺失值在公司CSV保留为空，不填零。

2026Q3中芯国际缺报：估算营收 = 2025Q3单季营收 ×（2026H1营收/2025H1营收）；估算归母净利润 = 估算营收 ×（2026H1归母净利润/2026H1营收）。结果分别为204.9799116841亿元和23.7021065379亿元，页面按显示精度取舍。估算是机械外推，不是业绩指引。估算不用作2026Q3季度末PE分母。

财务柱使用独立亿元刻度，页面显示其范围，不能用左侧市值轴读取。正利润已包含在营收柱总高度内；负利润显示为零线下红色块。空心PE点表示市值覆盖率不足100%。

## 紧凑布局

顶部独立汇总卡片已移除，总市值、PE、营收和归母净利润在图表内紧凑显示并随悬停更新。数据口径、估算公式、历史缺口、图表读法及来源集中在底部“数据口径与估算说明”，默认收起，展开后为紧凑滚动区。保存图表、下载数据和查看数据快捷按钮均已移除。桌面和手机已核验折叠、页签、缩放及搜索交互。

## 行业紧凑模块

最终界面为一行行业标题、主图和一行折叠页签。已移除顶部品牌栏、装饰英文、重复图标题、底部重复说明与独立汇总卡。指标以图内紧凑行显示；季度明细、公司明细、数据口径共用三个互斥折叠页签，默认全部关闭。主图桌面405px、手机340px，保留必要轴单位、估算符号和完整口径。当前仅制作电子，未新增其他行业数据。

时间快捷选项：1年、3年、5年、10年、20年、全部；分别选择最新4、12、20、40、80个季度或全部87季度，桌面与手机默认5年。

## 申万二级行业筛选

标题右侧增加二级行业多选，提供全部、半导体、消费电子、元件、光学光电子、电子化学品、其他电子；各项及已选合计显示2026Q3季末总市值。金额不随图表窗口或悬停变化。勾选后图表、季度明细、公司明细、覆盖与估算说明同步筛选，时间范围保留；取消全部时留空，不伪装为零值。组合PE重新汇总分子分母。`sectors.json/js` 为按已有公司季度明细与SW2021成分生成的二级行业聚合数据；六行业逐季和母行业原始市值、财务、PE分子分母全部对账通过。
