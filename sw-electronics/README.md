## 页面交互

顶部悬浮区统一管理全部行业的时间区间、指标开关、数值标签与财务模式；各一级行业独立管理二级行业复选和底部互斥折叠页签。总控制块的“展开全部二级 / 收拢全部二级”统一全选或取消全页面二级行业，后续懒加载模块继承当前状态；各模块仍可单独调整。二级行业默认不勾选，勾选后在一级大图下方呈现，桌面每行三个，按该行业最新季度市值降序排列。取消移除对应小图；“全选”支持批量选中/取消。

快捷范围1、3、5、10、20年及全部，默认10年。总市值/PE/营收/归母净利开关同时作用于对应一级大图和小图。利润固定在柱底，数字位于柱底下方；关闭利润时营收仍保持完整高度。普通滚轮在图上也能滚动页面，区间通过快捷选项、季度选择及滑块调整。

PE分位按所选区间内不高于目标PE的有效正PE样本占比计算，含相等值；电子/银行采用日度样本，其他行业为季度样本；以彩色横条和数值显示，低分位为绿色、中间为黄色、高分位为红色；主图随悬停目标季度变化，鼠标离开大图后恢复最新季度，小图汇总取最新季度。无有效样本显示—。各主图、小图顶部汇总始终显示总市值、PE、营收、归母净利润及PE分位，不随指标开关隐藏；图例仅控制绘图。

PE尖峰采用A规则：有效正PE至少8季，PE同时大于Q3+3×IQR及中位数3倍。先用非候选点计算纵轴上限；只有超出上限的候选点才压缩、虚线示意并标↑真实值。范围内候选仍按真实高度画实线。PE原值、分位、表格不修改，非正PE不显示且不跨缺口连线。

图表接近视口时才加载并初始化，各模块复用mountIndustry。补充数据表首次展开时生成。全部二级行业关闭时不创建小图实例。

## 数据与文件

电子、银行已于2026-11-13切换为与项目2同源的申万公布行情，覆盖一级和二级，包括银行无数据的“其他银行”。其余29个一级行业暂沿用公司整体法。两类模块由 meta.valuationMethod 区分，数据口径说明随模块切换。

- 电子、银行市值：sw_daily.total_mv÷10000，源单位万元、输出亿元；PE直接采用sw_daily.pe。季度点取季度末最后交易日的实际公布值，缺失不沿用、不与旧公司合成估值拼接。
- PE分位：电子、银行取所选起始季度首日至结束季度末日之间全部有效正日度PE，含相等值；其他模块保持季度样本。相同指数、观察日和日期范围时，与项目2同公式。2.2保留1位小数，项目2卡片通常取整数。
- 财务：仍为最新在市SW2021成分的全公司合并报表，上市后纳入固定回溯，保留单季度和最近4季。不是申万PE分母，不用市值÷PE推导真实净利润。公司明细市值仍用daily_basic.total_mv÷10000，与项目2公司明细同字段；不等于申万行业市值的拆分，A+H公司的全部普通股按A股价格估值。
- 当前快照日期统一为2026-11-10，最新完整财报季度2026Q3。电子一级行情可得起点2012-08-01、银行2014-02-21；更早市值/PE留空，财务仍从2005年展示。各二级历史覆盖见折叠说明。
- 原始公开行情：电子 `sw-source.json`，银行 `bank/sw-source.json`。记录12个有行情指数及1个无行情分类、API字段/参数/缓存校验摘要。2006年后复用项目2原始缓存；2005年补查接口，仅股份制银行有返回。
- `data.json/js`、`sectors.json/js` 与 `quarterly.csv` 已同步使用新口径；`valuationDaily` 保留分位用日度PE。`sw-alignment-audit.json` 记录日期覆盖和财务校验摘要。
- `catalog.json/js`：31行业排序及最新汇总；电子、银行采用申万总市值，其余仍使用公司汇总。`all-industries-audit.json` 中旧公司核验为历史审计，现行电子/银行行情看valuationAlignment。
- `company-quarterly.csv` 和公司的TTM字段用于财务及旧整体法复核，不作为新申万PE的分子/分母。旧银行data-audit、旧PE审计标记为历史口径，避免误作当前行情说明。

详细跨项目约定见 [SW_DATA_CONTRACT.md](SW_DATA_CONTRACT.md)。重建工具：`python3 tools/align_sw_data.py` 从随仓库保存的申万原始快照重建电子和银行；不联网，也不重新生成财报。

财务仍采用合并营业总收入（缺失时营业收入）、归母净利润，累计财报差分为单季。最新季度中芯国际使用同季营收增长及近期净利率估算并标*；银行齐全，不估算。北交所最早从2021-11-15纳入，智新电子不混入此前精选层阶段。萃华退缺财务等其余行业说明沿用原版本。原始财报缓存和旧构建脚本不得直接覆盖已切换的申万行情。

## 验证与发布

逐个核对电子、银行共13个指数分类的全部季度市值和PE、日度主键及缺失边界；使用项目2原窗口与原观察日核对其5,616个PE分位点。财务87季度、公司明细、估算与切换前逐字段相等，一二级财务仍可加总。市值与PE不要求一二级跨历史分类变更时相加。

网页校验包含一级/二级、PE分位随区间重算、全部指标关闭仍显示汇总、财务模式、申万空值、公司分组、折叠说明、鼠标移出恢复最新季度及手机布局。每次提交后运行工作区 `python3 sync-site.py`，同时同步旧公开站点仓库、新全览图仓库、本地副本与交付压缩包。

## 总标题与悬浮导航

页首显示“2.2 全览图”。其下为单行吸顶行业导航，顺序与最新市值排序一致。点击跳转到对应行业，页面滚动、二级图展开或折叠时自动更新当前行业高亮；横向导航会确保当前项可见。支持手机横滑、键盘链接操作、行业锚点及前进后退，遵循减少动态效果设置。

## 全局悬浮控制与最近4季

指标、时间范围、数值标签及财务模式统一控制全部一级/二级图，包括随后懒加载的图。任一主图滑块也更新全局区间。最近4季按该季与此前3季相加，窗口可以超出显示区间；不足4季、无样本或有财务缺失时留空，含估算保留标记。原季度数据不改动，底部明细仍是单季度；市值/PE不求和。

默认显示最近4季营收与归母净利润，PE曲线默认隐藏，顶部PE与分位始终显示；可通过全局开关恢复PE或切回单季度。懒加载行业及新增二级小图继承当前设置。

公司明细按二级行业分组，组间按最新季度行业总市值降序，组内按公司总市值降序。新增总市值（亿元）列，组标题列出行业总市值；搜索支持公司、代码和二级行业，估算筛选后仍保持该顺序及完整行业市值。
