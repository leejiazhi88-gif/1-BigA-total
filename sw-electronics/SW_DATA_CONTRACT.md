# 项目2 / 2.2申万取数约定

应用日期：2026-11-13。先用于2.2电子、银行及其二级行业，其余行业待后续切换。

## 同源与日期

行情来源为Tushare `sw_daily`，申万2021代码来自 `index_classify(src=SW2021)`。本次直接复用项目2截至2026-11-10的原始响应缓存；两个一级指数2026-09-30数据又经接口独立查询确认一致。2005年单独查询，只在股份制银行取得返回。公开原始响应、请求参数、行数和缓存SHA256记录在每个模块的 `sw-source.json`，不含凭据。

当前财务快照仍截至2026-11-10，图表截至最新完整财报季度2026Q3，不使用未结束的2026Q4。项目2末值截至2026-11-10，所以两页默认末值日期不同；比较必须同时指定指数代码和交易日。

## 分位窗口

2.2取选中起始季度第一天至结束季度最后一天，左右含边界。默认近10年（40季度）为2016-10-01—2026-09-30，共2,426个有效交易日（本次所有有行情目标指数在该区间PE均为正）。电子末日PE58.55，日度分位80.7%；银行末日PE6.41，日度分位54.0%。

项目2截至2026-11-10的近10年窗口为2016-11-10—2026-11-10，目标PE亦为11月10日，不能要求它与2.2季末分位相同。本次用项目2每个原窗口、每个原观察日核对5,616个历史分位点，四舍五入到项目2整数精度后全部一致；2.2显示1位小数。

2005年新增样本不在项目2从2006年开始的“全部”窗口内；若两页起点不同，分位也可不同。实际可得样本起点及样本数在折叠说明、汇总悬浮说明中显示。

## 利润不可倒推

申万公布总市值不是已经核实的指数PE计算分子；`total_mv / pe`只能称为隐含参考比值。项目2展示此比值的归一化曲线，不应与2.2真实财报柱等同。历史研究显示权重和利润切换规则可能不同，本项目直接采用申万公布PE，不宣称通过自由流通代理算法精确复现。

历史指数成分与固定最新财务样本也不同。公司市值保留与项目2公司明细一致的全部普通股按A股价格估值字段，含H股时不能误称仅A股总市值；公司金额和财报利润不强制与申万市值/PE相除对账。

## 历史与缺失

电子一级可得起点2012-08-01；银行一级2014-02-21。其余一级、二级分别使用各自真实可得日期。2005年以来财报可继续展示，缺失行情不会用自算值、零或未来值补齐。SW2021代码的早期记录可能包含旧分类名称及指数延续历史，不把早期回溯当作2021版分类当年已存在。

“其他银行”分类无公布行情、无当前公司，保持空值及提示。一级/二级PE分别读取自己的指数，不平均、不分摊；历史跨分类调整时二级市值之和不一定等于一级。

## 后续更新

工具 `tools/align_sw_data.py` 默认从仓库已保存的公开源响应重建，支持 `--project2 PATH --early-source PATH` 从项目2快照导入。财务原始数据及旧公司审计保留为独立口径，不能直接用旧构建器覆盖申万行情。校验并提交后执行工作区 `python3 sync-site.py` 同步两仓库和本地交付。

校验命令：`python3 tools/validate_sw_data.py`；可加 `--project2 PATH` 对比项目2原始分位输出。
