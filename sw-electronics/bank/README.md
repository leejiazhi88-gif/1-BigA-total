## 数据与口径

- `data.json` / `data.js`：行业汇总、公司明细、覆盖与估算信息。JS全局为BANK_DATA。
- `sectors.json` / `sectors.js`：4个二级行业的相同口径数据。JS全局为BANK_SECTOR_DATA。
- `company-quarterly.csv`：2,102条上市后公司季度记录。
- `quarterly.csv`：87季度总表。
- `data-manifest.json`：取数来源、参数及覆盖情况。
- `data-audit.json`：汇总核对、历史缺失、沿用市值及财报重建TTM的版本依据。

市值使用Tushare季度末daily_basic.total_mv（万元÷10,000为亿元），缺失时沿用此前有效报价，记录日期。该字段为总股本按A股价格计算的总市值，含其他股份类别的公司沿用相同字段，不额外叠加港股市值。

PE采用整体法含亏损：正PE股由当日市值/pe_ttm反推TTM利润；沿用报价或无有效PE时用季末已公告财报重建。合并、调整合并、调整前合并报表全部查询；按实际公告日筛选后选当时最新版本。同日优先1、4、5，优先update_flag=1。无法重建时同时剔除分子和分母，显示覆盖率。

财务取截至快照日可得合并营业总收入（缺失用营业收入）与归母净利润，累计差分成单季。银行净利息、净手续费等收入结构不同于工业企业，贷款/存款规模不作为营收。早期会计准则变更、调整报表、并购使历史可比性受限。最新季度缺报时沿用电子模块同样的估算规则；本次无估算。

## 已知边界

- 2007Q2中信银行缺2007Q1，无法对半年报差分。只展示其余公司已知营收/利润合计并标†，不补零。
- 2005Q4招商银行、2017Q1张家港行沿用停牌前市值，季末可得TTM不完整；PE市值覆盖分别59.47%、99.40%，空心点提示。
- 共11条公司季度市值沿用此前交易日记录。
- 最新固定成分回溯存在存续样本偏差；不是历史官方成分指数。

## 交互与验证

每个一级行业独立管理时间、指标开关、二级行业复选和折叠页签。PE分位与A规则尖峰处理完全复用电子逻辑；纵轴范围内仍为实线。利润固定堆叠在柱底，标签位于下方。鼠标在图内时普通滚轮滚动页面。
