# 申万PE、流通比例与财务柱核对

核查日：2026-11-17。航空机场801991.SI、IT服务801103.SI。PE直接与申万官网当日指数分析表核对，分别为56.49、95.72倍；不是网页自己算出的正数。

## 可以确认的算法差异

申万官网《申万系列指数之分析指标》（2010-12）第1—2页写明：

`指数PE = Σ(A股自由流通市值) / Σ(最近4季利润 × A股自由流通股数 / 总股本)`

自由流通权重为 `wᵢ=自由流通市值ᵢ/合计自由流通市值`，相同利润定义下等价于 `1 / Σ(wᵢ/个股PEᵢ)`，不是PE的算术加权平均，也不是全公司总市值除以全公司利润。

2025-10版《申银万国股价系列指数编制说明5.0》第5页、第26页再次确认自由流通市值权重。自由流通量还会从无限售A股中扣掉国有、战略投资者、部分管理层等持股，所以不能拿普通“流通股本/总股本”直接代替。

申万另有《申万行业市盈率、行业市净率算法说明》（2012-11）第2页明确写明：计算剔除亏损股、负净资产及暂停上市股票，不剔除ST股。但该文描述的是另一套行业估值统计（当时23个一级、85个二级），并规定剔除后不超过5家公司不出PE；不能仅凭该文就断言当前sw_daily的指数PE完全沿用同一剔除及归一化规则。

利润取期也不相同：指数说明按月份统一切换财报窗口，1—4月使用上年前三季加更前一年Q4，5—8月切到当年Q1，9—10月切到当年中报，11—12月切到当年前三季。网页每根财务柱按所标财务季度及当前已披露版本汇总。11月的目标窗口一致，并不能单独解释本次负利润/正PE现象。

## 实算结果

金额单位亿元；公司利润为2025Q4—2026Q3归母净利润。使用当日daily_basic与官网最新成分权重（接口未注明权重日期，四位小数）作诊断。

| 算法/指标 | 航空机场 | IT服务 |
|---|---:|---:|
| 网页全公司近4季利润（含亏损） | -100.29 | -79.49 |
| 仅盈利公司的利润合计 | 72.78 | 126.29 |
| 盈利公司总市值 / 盈利公司利润 | 25.81倍 | 54.15倍 |
| 官网权重下只保留正盈利贡献，亏损贡献按0、保留全部权重 | 56.82倍 | 96.50倍 |
| 上一行再把盈利公司权重归一化 | 26.54倍 | 53.43倍 |
| 申万官网 / sw_daily实际公布值 | **56.49倍** | **95.72倍** |

航空机场12家公司里，南方航空、中国东航、中国国航、海航控股合计近4季亏损约173.07亿元，超过其余8家的盈利72.78亿元，导致全公司合计为负。

直接按官方权重计入正负利润，航空机场仍会算出负值；因此**自由流通权重本身不足以解释本例**。亏损处理或申万实际使用的利润数据也必然不同。最接近公布值的实验是“按自由流通权重、负盈利贡献置零、保留全体权重”。但这不是已被官方确认的现行规则，不能把0.59%/0.81%的残差写成已完全复现。若假设官网权重对应前一交易日，用11月16日至17日价格变动调整权重，实验值变为56.47/95.84倍，说明权重日期也可造成差异；接口没有日期，不能凭接近程度证明该假设。

IT服务还有样本差异：官网指数123家公司，网页当前分类134家公司。官网样本不含网页中的12家北交所公司，并包含11月3日入选的北投科技600936.SH；其公司PE亦为空。仅移除12家北交所公司，网页共同122家公司利润仍约-80.81亿元，不能使合计转正。

## 页面处理与结论边界

保留官方PE及原始非正值，不拿财务柱强行重算或修改它。柱形继续展示全公司利润，包含亏损，不按自由流通比例缩放。正的申万PE不代表整个行业全部公司合计赚钱。

已经证实自由流通权重、样本、利润取期都与简单汇总不同，官网历史行业估值规则也确实排除亏损股。尚未取得当前每日估值逐股计算明细和明确权重日期，**无法断言当前指数是把亏损公司连市值一起删除，还是保留权重而把亏损盈利贡献置零**。如需精确到公布值的小数点后两位，需要申万提供当日逐股自由流通股数、采用的归母TTM利润和亏损/负净资产处理规则。
